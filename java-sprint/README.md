# Java Sprint

A hands-on Java learning sprint aimed at junior-developer readiness. It is written for someone who can already program a little — a CS student with some Python is the assumed reader — but who has never written Java. The format is the same throughout: a lesson you read, examples you run, exercises that start from a compiling file with `TODO`s in it, and solutions you open only after your own attempt. Everything targets **JDK 21**, and everything runs from a terminal or IntelliJ IDEA Community with no build tool in the way.

## Day 1 — Java from zero to a working program

**[Start here → day-1/README.md](day-1/README.md)**

Nine modules taking you from "what is a JVM" to a small program you built yourself. The first eight cover one idea each: setup and Hello World and how to read a compiler error, variables and types, control flow and `Scanner` input, methods and decomposition, classes and objects and encapsulation, inheritance and interfaces and polymorphism, `toString`/`equals`/`hashCode`, and exceptions and stack traces. The ninth is a capstone that assembles all of it into a console contact book with a menu loop, a model class that refuses invalid data, an `ArrayList`-backed store, and `try`/`catch` at the edge so a typo produces one friendly line instead of a crash. Budget a full day: roughly eight hours for modules 01–08 and another two and a half to three for the capstone. The Day 1 guide has the schedule, the one-time setup checklist, and a completion checklist.
